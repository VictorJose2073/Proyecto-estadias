# HRL Refacciones Laptop

Frontend de la plataforma web pública de HRL, construido con Vue 3, Vite,
Vue Router y Pinia.

## Requisitos

- Node.js compatible con Vite 8.
- npm.

## Instalación

```sh
npm ci
```

## Desarrollo local

```sh
npm run dev
```

## Validaciones

```sh
npm run lint
npm run build
```

Para previsualizar localmente la compilación de producción:

```sh
npm run preview
```
